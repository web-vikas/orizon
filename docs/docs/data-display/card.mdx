# Card

A container for displaying content with an optional header, cover, and actions.

## When to Use

- To group related information in a box
- For product listings, profile cards, or summaries
- When content needs a header with title and actions

## Import

```tsx
import { Card } from "orizon";
```

## API

### CardProps

- `title` — `ReactNode` — Card header title
- `extra` — `ReactNode` — Extra content in header (e.g., links)
- `cover` — `ReactNode` — Cover image at top
- `actions` — `ReactNode[]` — Action list at bottom
- `bordered` — `boolean` — Show border (default: `true`)
- `hoverable` — `boolean` — Lift on hover (default: `false`)
- `loading` — `boolean` — Show skeleton placeholder (default: `false`)
- `size` — `"default" | "small"` — Card size (default: `"default"`)
- `type` — `"inner"` — For nested cards
- `bodyStyle` — `CSSProperties` — Body container styles
- `headStyle` — `CSSProperties` — Header styles

### Card.Meta Props

- `title` — `ReactNode` — Meta title
- `description` — `ReactNode` — Meta description
- `avatar` — `ReactNode` — Avatar element
