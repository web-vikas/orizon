# Empty

A placeholder for when there is no data to display.

## When to Use

- For empty states in lists, tables, or search results
- When content has been cleared or filtered to nothing
- To prompt users to take action when a section is empty

## Import

```tsx
import { Empty } from "orizon";
```

## API

### EmptyProps

- `description` — `ReactNode | false` — Description text (set `false` to hide)
- `image` — `ReactNode` — Custom empty illustration
- `imageStyle` — `CSSProperties` — Image container styles
- `children` — `ReactNode` — Action area below description
