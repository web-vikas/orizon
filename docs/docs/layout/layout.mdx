# Layout

High-level page structure components for Header, Sider, Content, and Footer arrangements.

## When to Use

- To define the overall page structure with header, footer, content, and sidebar
- For admin dashboards and application shells
- When you need a collapsible sidebar layout

## Import

```tsx
import { Layout } from "orizon";

const { Header, Sider, Content, Footer } = Layout;
```

## API

### Layout Props

- `hasSider` — `boolean` — Whether contains a Sider (auto-detected)
- `className` — `string` — Custom CSS class
- `style` — `CSSProperties` — Inline styles

### Layout.Header / Layout.Footer / Layout.Content

- `className` — `string` — Custom CSS class
- `style` — `CSSProperties` — Inline styles

### Layout.Sider Props

- `collapsed` — `boolean` — Current collapsed state
- `collapsible` — `boolean` — Whether can be collapsed (default: `false`)
- `collapsedWidth` — `number` — Width when collapsed (default: `80`)
- `width` — `number | string` — Width of the sidebar (default: `200`)
- `breakpoint` — `"xs" | "sm" | "md" | "lg" | "xl" | "xxl"` — Breakpoint for auto-collapse
- `theme` — `"light" | "dark"` — Color theme (default: `"light"`)
- `trigger` — `ReactNode` — Custom collapse trigger element
- `reverseArrow` — `boolean` — Reverse collapse arrow direction (default: `false`)
- `onCollapse` — `(collapsed: boolean, type: string) => void` — Collapse callback
- `onBreakpoint` — `(broken: boolean) => void` — Breakpoint trigger callback
