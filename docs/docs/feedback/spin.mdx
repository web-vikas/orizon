# Spin

A loading spinner for indicating content is being fetched or processed.

## When to Use

- To indicate a loading state for a section or the entire page
- As an overlay on content that is being refreshed
- For async operations in progress

## Import

```tsx
import { Spin } from "orizon";
```

## API

### SpinProps

- `spinning` — `boolean` — Whether to show spinner (default: `true`)
- `size` — `"small" | "default" | "large"` — Spinner size (default: `"default"`)
- `delay` — `number` — Delay before showing (ms), prevents flicker
- `indicator` — `ReactNode` — Custom spinner element
- `tip` — `ReactNode` — Loading text
- `description` — `ReactNode` — Description below tip
- `fullscreen` — `boolean` — Cover the entire viewport (default: `false`)
- `percent` — `number | "auto"` — Progress percentage
